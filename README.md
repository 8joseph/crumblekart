<h1>Crumblekart</h1>
Onlime multiplayer kart racing game similar to Mario Kart, made in Godot.
<h2>Features</h2>
<ul>
<li>Online multiplayer</li>
<li>Two vehicles with distinct handling</li>
<li>Boost/Drift mechanic</li>
<li>Lobby screen</li>
</ul>
